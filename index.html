Model & contract reference
  • Inputs (8, in session order): 5 float32 [N,1] — GWA, Number_of_Failed_Courses, Number_of_Dropped_Courses, Total_Units_Taken, Year_Level; 3 string [N,1] — Course_Program_Enrolled, Enrollment_History, Previous_Academic_Standing.

  • Risk bands: Low 0–0.39 · Medium 0.40–0.69 · High 0.70–1.00 (applied to P(at-risk)).
  • Parity reference (onnx_parity.json): all 4 models converted, opset 14, predictions exact-match, max |Δproba| ≤ 1e‑5. Frontend sends NaN / "" for missing.
